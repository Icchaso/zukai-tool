# 図解ツール

AIに「◯◯を図解して」と話しかけるだけで、解説つきの図解Webページを自動生成し、共有用URLまで発行するツールです。

- 作った図解はURLひとつで人に共有できます（例: `https://diagram-coffee-a1b2c3.surge.sh`）
- 手元の `output/` フォルダにも保存され、ブラウザで開けばそのまま閲覧・PDF化できます
- プログラミングの知識は不要です。セットアップもAIが案内します

## 必要なもの

- **VS Code**（無料エディタ） — https://code.visualstudio.com/
- **Claude Code 拡張機能** — VS Code 左側の拡張機能アイコンから「Claude Code」を検索してインストール
- **git** — Macは最初から使えます。Windowsは [Git for Windows](https://gitforwindows.org/) を入れてください（このツールが使う Git Bash も一緒に入ります）
- Node.js や公開サービスのアカウントは、**無くてもAIがセットアップ中に案内・自動導入します**

## はじめかた

1. VS Code でターミナルを開きます（メニュー「ターミナル」→「新しいターミナル」）
2. 次の1行を貼り付けて Enter:
   ```bash
   git clone https://github.com/Icchaso/zukai-tool.git
   ```
3. メニュー「ファイル」→「フォルダーを開く」で、いまダウンロードされた `zukai-tool` フォルダを開きます
4. Claude Code のパネルを開いて、**何でもいいので話しかけてください**（「はじめまして」でOK）

初回はAIがツールの説明と、公開用サービス Surge（サージ）の無料アカウント登録を案内します。あなたがやるのは**メールアドレスとパスワードを決めて入力するだけ**です。

## 使い方の例

- 「インスタントコーヒーの美味しい入れ方を図解して」
- 「Web広告の仕組みを、自分の勉強用に図解して」
- 「この資料を、お客さんに見せる提案用に図解して」（ファイルを渡してもOK）
- 「この図解を削除して」（公開したURLを取り下げます）

## 知っておいてほしいこと

- 公開URLは推測されにくいランダムな文字列つきで、検索エンジンにも載らない設定です。ただし**URLを知っている人は誰でも見られます**（パスワード保護はありません）。他人に見られて困る内容は公開しないでください
- 公開をやめたいときは、AIに「この図解を削除して」と伝えるだけで取り下げられます
- ツールの更新を取り込みたいときは、このフォルダで `git pull` を実行してください
